# Epicast — Mage and Druid crests

**0.1.0-beta.18.segments.1 · WoW Forever (16001)**

Independent artwork and native effects for spells and resources. Mages choose **Fire, Frost and Arcane** book crests; Druids choose **Balance, Feral and Restoration**. Each complete crest has gentle six-second hovering, with independently adjustable size and position.

The new Mage trio uses icy, molten and knotted-rope crowns with matching pendants and floating crystal accents. It replaces the earlier Mage artwork. Effects and bindings are now baked into each crest and supplied by the addon.

On first use, **Crests → Spellcasting** shows your class's artwork cards. Check **Show** for any combination and select a card to edit that crest. **Save all changes** keeps edits across every tab and crest; Cancel or Close discards unsaved previews. Close is labeled **Discard & close** when edits are pending. Choices do not follow your talent specialization automatically. Each crest keeps its position, size and effects when hidden. Existing Druid settings migrate **Moonwarden → Balance** and **Groveheart → Restoration**, with those two initially selected. Restoration includes nine recovered, baked layers for Regrowth, Healing Touch, Rejuvenation, Swiftmend and two static nature accents. Balance and Feral currently have no baked spell effects.

Every Arcane crest uses **12 tuned effect layers**: six static accents and six bindings for Arcane Blast (cast and success), Missile Barrage (Buff), Arcane Explosion (success), and Arcane Missiles (pulse and channel). The Barrage layer includes intro and outro segments. Fire and Frost start with empty effect lists for authoring.

Addon updates apply the latest baked effects automatically, including on existing installations. Old developer overrides and intentionally empty personal effect lists no longer replace the crest definition. Your normal settings—crest choices, position, size, facing, animation, resource choices and global preferences—remain saved. No manual configuration deletion is required.

This build replaces shared set placement with independent crests. Existing sizes, screen positions, facing and visibility are converted once into individual settings. Moving, resizing, hiding or showing a crest leaves the others in place. The former linked spacing and set-wide size controls are removed.

Close WoW completely before installing or updating. Extract the `Epicast` folder into `Interface/AddOns`, restart WoW, and enable Epicast. A full restart allows newly added Lua files to be discovered. Click the Epicast icon on the minimap or in OneForAll’s **Collect minimap buttons** bar. You can also use **`/epicast`** or **`/epic`**. Epicast has its own settings and does not require EndCapper, an action-bar addon, or WeakAuras. If both Epicast and EndCapper are enabled, their artwork can overlap; hide the unwanted artwork in either addon.

- **Crests** contains Spellcasting and Resources. A card selects what you edit; its **Show** checkbox controls what appears in-game. Hidden crests remain editable.
- **Placement** has a size slider and exact size/position inputs. Enter commits a number; Escape reverts unfinished text; Tab moves between fields. Use +/- to nudge by 1, or hold Shift for 10. Horizontal 0 is screen center; height 0 aligns the crest's outline to the bottom. Size ranges from 5% to 400%.
- Drag a shown crest's outline while Placement is open. **Center horizontally**, **Align to bottom** and **Reset placement** affect only the selected crest. Reset changes size and position; effects and bindings remain intact.
- **Behavior** controls animation and effects together and shows the configured spell responses. Resource kind and meter controls also live here. Turning animation off keeps the artwork still and hides its effects.
- Resource 1 and Resource 2 currently have no custom artwork and start hidden. Each has its own visibility, size, position, resource and meter. Choose health, mana, energy, rage, focus, runic power or current power. Native effect intensity and optional meters follow the current level.
- **Settings → Hide Blizzard endcaps** is optional and off by default. Epicast never uses them for its placement.
- **Settings → Hide Cooldown Manager (keep tracking active)** is optional and off by default. It makes CDM's four displays transparent while preserving native tracking. Edit Mode and CDM settings temporarily reveal them; Save/Cancel also covers this setting.
- **Settings → Show resource crests only on Mages** controls the Resources class filter. Other classes can preview resources while editing; uncheck this setting to display them after closing options. Spellcasting crests always belong to your character's class during normal play. Talent specialization and shapeshift form do not alter your selection.

Developer mode starts enabled in this test build. **Settings → Developer mode** and **`/epicast dev`** toggle it for the current session. The session-only **Preview class** menu above the crest cards previews any of the nine Forever classes; the effect studio also has a Class menu. Each class has three independent spec slots. Other classes' slots await dedicated artwork and can already hold effects. Close options or turn off developer mode to restore your character's class; the preview class is never saved. Select a crest and choose **Open effects** beside its title to preview edits from either Placement or Behavior. Effect changes are session-only: Save session keeps a temporary checkpoint, and reload loses it. Before reloading, use **Copy crest bake** in the studio footer or Behavior and copy the export for the addon builder to include in a release. Only the normal UI preferences persist in your game settings.

The effect library contains **8,723 native effects filtered for Forever 1.60.1.70938**, including spell and particle effects across classes. The studio's crest menu selects any artwork by name. Search effects by name, path, aliases or numeric FileDataID. Missing assets, the error cube and empty models are excluded. Preview loading and placeholder checks must pass before adding an effect. Models load from the game; Epicast does not bundle native game files.

The developer studio has two tabs:

- **Effect Library** searches and previews game effects. **Add effect layer** creates one new layer on the selected crest and opens Artwork Config.
- **Artwork Config** shows a live crest preview, a full Layers sidebar and a Spell waiting room. Layers at the top render in front; use **Forward / Backward** to place effects above or below the artwork. Select a layer to edit Placement or Playback. Exact fields support Enter and mouse-wheel nudging (Shift multiplies the step by ten).

Add spell or buff names/IDs to the waiting room. Click **Enter bind mode** to select a layer and stage several spells, or select a spell and stage several layers. Click a staged row again to deselect it, then click **Save binding** or **Cancel binding** to exit. In ordinary selection, linked spells highlight blue and linked layers highlight green.

Click the gear beside a spell to open **Spell Mappings**. Pick a game trigger, then check the artwork states it should play on each linked layer. A new artwork link waits for its first mapping. A new native effect link starts with **Cast succeeds**. To change a native effect's trigger, select one and click **Use trigger** beside the effect.

For Restoration, link the feathers to **16870**, then select **While buff active** and check **Channel** for both feathers. For Regrowth, map **While casting** to Channel and **Cast succeeds** to Impact. Channel holds while a sustained trigger is active. A burst trigger plays a short Channel with the usual ramps. Impact plays once per trigger activation and takes priority over Channel.

The **All** filter shows effects and artwork in render order. **Artwork** lists artwork layers. **Static** and **Bound** list effect layers by binding state. Use the spell menu in Playback to edit each linked response. **Unbind spell** removes an assignment and keeps the spell available for reuse. A native effect becomes always active when its last link is removed. **Test response** runs in the full-crest preview and lets you choose a response when both artwork options are enabled. Actual player spells also drive that preview when the crest's Behavior has effects enabled.

**Follow artwork motion** attaches an effect to the selected artwork layer's motion while retaining its placement offsets. Restoration has individually selectable artwork segments. The other Mage and Druid crests show one **Crest artwork** layer each. Unavailable artwork is not presented as an editable layer. Each crest supports 32 effects and 64 waiting-room spells. Available animation metadata covers 74 inspected models; others remain labeled unverified. Resource layers cannot be bound to spells.

The waiting room, layer order, artwork opacity/visibility and motion attachments belong to the crest bake. **Save session** checkpoints all developer edits in RAM; **Copy crest bake** exports the selected crest for the addon builder. Reload loses session edits. Closing just the studio returns to the main editor with its draft; closing the main editor discards uncommitted edits. Neither developer settings nor waiting-room spells are stored in player profiles.

Model **166602** contains only Stand (animation 0), with no separate Intro/Hold/End segments. This build corrects unsupported settings for it. Its global animation loops and existing particles may resume on subsequent triggers; a fresh initial particle appearance is not guaranteed. Trigger reports now include the last requested segment ID.

Bindings use public player events. Some models lack intro/hold/end segments, and some game data may be restricted. Unverified segments are labeled; unavailable resource values display `—`. No guessed projectile timers or synthetic resource readings are used.

Missile Barrage and Druid Clearcasting effects also read Blizzard's Cooldown Manager during combat. Enable the Cooldown Manager in WoW settings and include **Missile Barrage** or **Omen of Clarity / Clearcasting** in **Tracked Buffs** or **Tracked Bars**. Set the relevant viewer to **Always** in Edit Mode. You can then use Epicast's **Hide Cooldown Manager** option to hide its display without disabling tracking. Setting a viewer to Hidden or disabling CDM in WoW stops native tracking; Epicast does not change those game settings. Ordinary readable buff data remains a fallback when native tracking is unavailable.

The native tracker may identify Clearcasting as Omen of Clarity **16864**, and Epicast matches both IDs. Missile Barrage likewise uses **While buff active** with aura **400589**. **While proc glows** tracks action-button overlay signals. The native tracker must remain available when the game restricts direct buff reads.

If an effect fails, run `/epicast triggers` or use **Trigger report** under **Crests → Behavior** in developer mode while the missed buff is active. The report includes the trigger-code version, spell/aura event counts, all bound effects and playback state. It reports Tracked Buffs and Tracked Bars separately for each configured supported buff, including visibility, Clearcasting/Barrage matches, metadata IDs and public active state. Include these native rows as well as the effect lines when reporting a missed proc. A hidden unused row no longer masks an unmatched visible row as `hidden`.

For these buffs, `cooldown=active` or `inactive` confirms native detection. `untracked` means no matching item was found in a readable visible row; `restricted` or `unknown` means no readable state was available. Hidden-row item details are diagnostic only, because hidden viewers may stop updating. `module missing` means the reader was not loaded: extract the entire ZIP and fully restart WoW. Reader/binding errors are isolated from other triggers and included in the report. Barrage and Clearcasting detection changes still need confirmation on the affected clients.

This is a testing build. Local integration and source asset checks pass; actual client appearance and spell/event availability still need in-game testing. The library's file checks do not verify every animation or appearance in-game.
