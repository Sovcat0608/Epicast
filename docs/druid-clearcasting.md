## Implementation

- Added a Druid-only profile for Clearcasting/Omen of Clarity, aura **16870** and talent/native tracker **16864**. Both exact IDs, English names and localized names resolve the native mapping. Mage Clearcasting (12536 / 11213) and Shaman Clearcasting remain excluded. Existing Missile Barrage behavior is preserved.
- Buff bindings only. `While proc glows` retains its existing action-overlay semantics; it is not silently rewritten into buff detection. Studio feedback directs Clearcasting users to `While buff active` and visible native tracking.
- The one existing 0.1-second polling loop continues to run only while eligible visible layers exist. Each event/poll batch now caches snapshots by proc key, preventing one buff's active state from being reused for a different buff. Multiple layers for one proc share that proc's sample.
- Read only public booleans from `IsActive`/`isActive` on matching native buff items. Ignore hidden/editing/demo viewers and unavailable, restricted, unknown or conflicting states; retain public aura fallback. No native refresh hooks, aura-instance reads, visibility-based activity guesses, inferred consumption/timers, settings mutation or model reloads.
- `/epicast triggers` now reports revision **0.1.0-beta.7** and prints native rows for the configured supported buffs. Clearcasting reports include both native viewers, mapped matches and public status. Missing/error bridge protection still isolates other trigger kinds.

Sources: [ProcDoc's Druid mapping](https://github.com/wsmaxcy/ProcDoc/blob/main/ProcDoc.lua#L438-L448), [Blizzard Forever's native viewer](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_CooldownViewer/CooldownViewer.lua), and [aura API restrictions](https://raw.githubusercontent.com/Gethe/wow-ui-source/forever/Interface/AddOns/Blizzard_APIDocumentationGenerated/UnitAuraDocumentation.lua). No third-party implementation copied.
