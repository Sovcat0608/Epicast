## Restoration performance beta

- Warms the active Restoration crest’s opening texture pages outside combat and prepares the artwork and effect frames used by Tranquility.
- Reduces repeated visibility and opacity updates during idle playback and Tranquility. Keeps the existing artwork, effects and animation timing.
- Includes the v16 Restoration, Balance, Arcane and Frost crest packs from the tested WoW Forever build.

For testing, compare Epicast’s recent CPU time at idle and during Tranquility in the same scene and at the same frame rate.

Close WoW Forever completely before updating. Extract `Epicast` from the release ZIP into `Interface/AddOns` and restart the client. The installable ZIP includes all required artwork. GitHub’s automatic source archive is for code inspection.

Epicast is free to use. See the included licence for the terms covering the original code, crest artwork and animations.
